# Full-Stack Learning Journey (Udemy)

This repository documents my learning progress in **full-stack web development**.
It contains both **course-based learning materials** and a **personal portfolio website**
where I independently rebuild selected projects.

The goal of this repository is to build a **strong foundation in frontend and backend development**
and gradually create portfolio-ready projects.

## 📁 Repository Structure

This repository is organized as a **monorepo** with two main folders:

- **WebDevBootcamp-2026-Udemy**  
  Contains learning materials, exercises, notes, and experiments
  created while following the Udemy course lectures.

- **phucle-portfolio**  
  Contains my personal portfolio website and demo projects.
  Projects in this folder are implemented **from scratch**, without copying tutorials,
  and are intended for showcasing my skills.

Course code and portfolio code are intentionally kept **separate**.

## 🧠 Learning Approach

- Course materials are followed **selectively**:
  - Topics I am already familiar with may be skimmed
  - Topics that are unclear are practiced in depth
- Simple or repetitive projects may be skipped
- After completing a topic, I:
  - Rebuild selected ideas independently
  - Implement clean versions in the portfolio folder
- All work is version-controlled using **Git and GitHub**
